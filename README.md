# AI-Driven IDS with SOAR-lite Integration

An AI-driven Intrusion Detection System (IDS) integrated with a lightweight SOAR backend, designed to improve financial-sector cybersecurity.
This system uses a RandomForest model trained on the CICIDS2017 dataset, with FastAPI services for scoring and SOAR orchestration, and a Streamlit analyst console for interactive triage.

---

## 📌 Features

- **Machine Learning IDS**: RandomForest classifier trained on CICIDS2017.
- **SOAR-lite backend**: FastAPI service with YAML playbooks for automated responses.
- **Analyst Console**: Streamlit dashboard for monitoring incidents and applying manual/auto actions.
- **One-click startup**: `start_system.py` launches all components.
- **Reproducibility**:
  - Fixed seeds, pinned dependencies.
  - Persisted model artifacts (`.joblib`, `.json`).
  - Action history stored in `.run/solved_archive.csv`.

---

## 📊 Results

The RandomForest classifier was trained and evaluated on the CICIDS2017 dataset,
normalised into 7 coarse classes (Benign, DoS/DDoS, Brute Force, Web Attack,
PortScan, Infiltration) using 77 numerical features and a stratified 60/20/20
train/validation/test split (`random_state=42`).

**Headline metrics:**

| Metric | Result |
|--------|--------|
| Macro F1-Score | **91%** |
| ROC-AUC | **94%** |
| Feature efficiency | Top 20 features retained **97%** of full F1 performance |

**Per-class performance:** Benign and DoS/DDoS classes achieved near **0.95**
precision, recall, and F1. Web Attack detection was slightly lower but remained
effective. The confusion matrix showed strong diagonal detection (e.g. 880 Benign
and 910 DoS/DDoS instances correctly classified) with minimal off-diagonal error.

**Baselines:** The Random Forest model was benchmarked against Logistic Regression
and an RBF-kernel Support Vector Machine to validate its suitability for real-time
scoring.

Evaluation plots (confusion matrix, ROC curves, per-class precision/recall, and
the precision–recall vs. threshold trade-off) are generated by
`evaluate_and_plots.py` and saved to `/reports`.

## 🏗️ Architecture

```
[Replay Harness] → [Model API (FastAPI)] → [SOAR-lite Backend] → [Streamlit Console]
```

- **Replay Harness** (`replay_from_parquet.py`): Feeds CICIDS2017 events for demo.
- **Model API** (`score_api.py`): Exposes `/score` endpoint for predictions.
- **SOAR-lite API** (`soar_api.py`): Executes or simulates response playbooks.
- **Streamlit Console** (`app.py`): UI for analysts with incident triage tools.

## ⚙️ Setup Instructions

> **Requirements:** Python **3.11 (64-bit)**. The pinned dependencies (notably
> scikit-learn 1.7.1) match the version the model was trained with, so use 3.11
> for reproducible results. Newer Python versions may fail to load the saved model.

### 1. Clone the Repository

```bash
git clone https://github.com/ravin9860/ai-ids-soar.git
cd ai-ids-soar
```

### 2. Create and Activate a Virtual Environment

**Windows (PowerShell):**
```powershell
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS / Linux:**
```bash
python3.11 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Start the System

```bash
python start_system.py
```

This launches:

- Model API on **http://localhost:8000**
- SOAR-lite API on **http://localhost:7000**
- Analyst Console on **http://localhost:8501**

The launcher uses whichever Python is running it, so make sure your virtual
environment is activated first.

## 🎛️ Usage

1. Open the **Streamlit Console** in your browser: `http://localhost:8501`
2. Replay dataset events:

   ```bash
   python scripts/replay_from_parquet.py
   ```

3. Monitor alerts in the console:
   - View **All Incidents**
   - Mark incidents as **Solved** (persistent archive in `.run/solved_archive.csv`)
   - Apply SOAR actions: `block_ip`, `quarantine_host`, `allow_false_positive`, `escalate`.

---

## 🚨 SOAR-lite Actions

Implemented in `soar/actions.py`:

- **block_ip** → Blocks traffic (Windows: `netsh`, Linux: `iptables` fallback).
- **quarantine_host** → Isolates machine (dry-run mode).
- **notify** → Logs alert/escalation.
- **escalate** → Flags for higher-level review.

> Dry-run is enabled by default (`SOAR_DRY_RUN=true`). Set to `false` for real
> blocking actions (run as Administrator on Windows).

## 📜 Limitations

- Dataset limited to **CICIDS2017** (no live traffic or UNSW-NB15).
- SOAR-lite is **not full StackStorm**, but extendable.
- Suricata integration left as **future work**.

> **Note:** This project was originally developed on a Windows 11 ARM laptop
> using an x64 emulation environment. It now runs on any platform with standard
> Python 3.11 (64-bit) — no ARM-specific setup required.
